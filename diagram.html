Daily Website Observer: ABM Trigger Intelligence

Pilot architecture. Python + SQLite + Claude API + Slack webhook + Streamlit. Nothing alerts unless it survives every gate.

System flow

Inputs
Account listCompany, URL, industry, owner, priorityaccounts.csv, 20 synthetic accounts
Page list3-5 pages per accountProduct, Pricing, About, News, Careers
Dummy websitesStatic HTML on localhost:8000You edit these live during the demo
Previous snapshotLast cleaned text blocksfrom SQLite
Trigger"Run observer" button / CLIDaily schedule documented, not demo-critical
Processing
1Fetchrequests, 10s timeout, 1 retry
2CleanStrip script/style/nav/footer/cookie banners
3Extract text blocksHeadings, paragraphs, list items
4Hash + block diffdifflib: added[] / removed[]
5LLM analysisJudge, classify, summarise, why it matters, outreach angle, evidence quote
6Validate + dedupeEvidence must appear in the diff; fingerprint check
Decisions
D1First time seen?
save baseline, no alert
D2Hash unchanged?
log "unchanged"
D3Only noise left?year, cookie, nav, footer, trivial rewording
log "ignored" + rule name
D4LLM: meaningful?Generic wording, formatting, boilerplate = no
log "ignored (LLM)" + reason
D5Evidence valid, confidence High/Med, not duplicate?
Low confidence goes to dashboard Review
Outputs
Slack alert#gtm-triggersChange, signal type, why it matters, outreach angle, source, confidence
Dashboard change feedAlerted / Ignored (with reason) / ReviewThe proof the filter works
Snapshot + diff viewerBefore/after, evidence highlighted
Run logPages checked, changed, alerted, errors
GTM action
BDR reads the alert30-second triage instead of manual site checking
Copies / adapts the outreach angleSpecific detail, tied to the signal
Sends timely outreachThe human sends. Nothing is auto-sent.
Shares context with AESource URL + evidence quote
